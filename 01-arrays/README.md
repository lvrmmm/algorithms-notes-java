# Массивы и два указателя

Массив хранит элементы одного типа в непрерывной последовательности и предоставляет доступ по индексу за `O(1)`.

У Java-массива есть две разные характеристики:

- `data.length` — физическая ёмкость, которая не меняется после создания;
- логический размер — количество элементов структуры, которые действительно используются.

Если массив используется как собственная структура данных, логический размер удобно хранить отдельно в `currentSize`. Рабочая часть массива занимает диапазон `[0, currentSize)`. Значения правее этого диапазона не являются элементами структуры, даже если физически находятся в памяти.

## Основные операции

| Операция | Неупорядоченный массив | Отсортированный массив |
|---|---:|---:|
| Доступ по индексу | `O(1)` | `O(1)` |
| Поиск | `O(n)` | `O(log n)` |
| Добавление в конец | `O(1)` | — |
| Вставка с сохранением порядка | — | `O(n)` |
| Удаление со сдвигом | `O(n)` | `O(n)` |

Бинарный поиск ускоряет нахождение позиции в отсортированном массиве, но вставка и удаление остаются линейными из-за сдвига элементов.

## Метод двух указателей

Два индекса могут выполнять разные роли:

- `read` читает ещё не обработанные элементы;
- `write` указывает место следующей записи;
- `left` и `right` могут двигаться навстречу друг другу с двух концов массива.

Типичный инвариант для пары `read` и `write` формулируется так: перед каждой итерацией диапазон `[0, write)` уже содержит правильный результат для обработанной части массива.

Этот приём используется в задачах на удаление элементов, перемещение нулей, объединение отсортированных массивов и работу с квадратами отсортированного массива.
