# 1089. Duplicate Zeros

- Сложность: Easy
- Темы: массив, два указателя
- Ссылка: https://leetcode.com/problems/duplicate-zeros/

## Условие

В массиве фиксированной длины нужно продублировать каждый ноль, сдвигая следующие значения вправо. Элементы, выходящие за границу, отбрасываются.

```text
[1, 0, 2, 3, 0, 4, 5, 0]
->
[1, 0, 0, 2, 3, 0, 0, 4]
```

## Решение 1. Сдвиг после каждого нуля

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == 0) {
                for (int j = arr.length - 1; j > i; j--) {
                    arr[j] = arr[j - 1];
                }
                i++;
            }
        }
    }
}
```

Сдвиг выполняется справа налево, чтобы не затереть исходные значения. После вставки `i++` пропускает созданную копию нуля.

- Время: `O(n²)` в худшем случае.
- Дополнительная память: `O(1)`.

## Решение 2. Воображаемый расширенный массив

Сначала считаем нули. Индекс `write` представляет позицию в массиве, который был бы длиннее исходного на число нулей. Физически этот массив не создаётся. Запись выполняется только тогда, когда `write` попадает в настоящие границы.

```java
class Solution {
    public void duplicateZeros(int[] arr) {
        int zeroCount = 0;

        for (int value : arr) {
            if (value == 0) {
                zeroCount++;
            }
        }

        int read = arr.length - 1;
        int write = arr.length + zeroCount - 1;

        while (read >= 0) {
            int value = arr[read];

            if (write < arr.length) {
                arr[write] = value;
            }
            write--;

            if (value == 0) {
                if (write < arr.length) {
                    arr[write] = 0;
                }
                write--;
            }

            read--;
        }
    }
}
```

Каждую из двух позиций нуля нужно проверять отдельно. Первая копия может находиться за границей, а вторая уже попадать в настоящий массив.

- Время: `O(n)`.
- Дополнительная память: `O(1)`.
