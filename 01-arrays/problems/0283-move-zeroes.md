# 283. Move Zeroes

- Сложность: Easy
- Темы: массив, два указателя
- Ссылка: https://leetcode.com/problems/move-zeroes/

## Условие

Нужно переместить все нули в конец массива, сохранив взаимный порядок ненулевых элементов. Изменение выполняется на месте.

## Решение обменами

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int left = 0;

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] != 0) {
                int temp = nums[left];
                nums[left] = nums[right];
                nums[right] = temp;
                left++;
            }
        }
    }
}
```

Перед каждой итерацией:

- `[0, left)` содержит ненулевые элементы в исходном порядке;
- `[left, right)` содержит нули;
- начиная с `right` находятся ещё не обработанные элементы.

Если просто копировать `nums[left++] = nums[right]`, ненулевые элементы соберутся в начале, но справа останутся старые значения:

```text
Исходный массив:    [0, 1, 0, 3, 12]
После копирования: [1, 3, 12, 3, 12]
Нужный результат:  [1, 3, 12, 0, 0]
```

Обмен сразу перемещает нули за собранную часть.

## Сложность

- Время: `O(n)`.
- Дополнительная память: `O(1)`.
