# 26. Remove Duplicates from Sorted Array

- Сложность: Easy
- Темы: отсортированный массив, два указателя
- Ссылка: https://leetcode.com/problems/remove-duplicates-from-sorted-array/

## Условие

Из отсортированного массива нужно удалить повторяющиеся значения на месте. Первые `k` позиций должны содержать уникальные элементы в исходном порядке.

## Решение

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int write = 1;

        for (int read = 1; read < nums.length; read++) {
            if (nums[write - 1] != nums[read]) {
                nums[write] = nums[read];
                write++;
            }
        }

        return write;
    }
}
```

## Почему достаточно последнего сохранённого элемента

В отсортированном массиве одинаковые значения расположены подряд. Если текущий элемент отличается от последнего сохранённого, это новое значение.

В неотсортированном массиве правило не работает. Для `[1, 2, 1]` последняя единица отличается от последнего сохранённого значения `2`, хотя единица уже встречалась.

`write` одновременно является количеством сохранённых элементов и индексом следующей свободной позиции. Последний сохранённый элемент находится по адресу `write - 1`.

## Сложность

- Время: `O(n)`.
- Дополнительная память: `O(1)`.
