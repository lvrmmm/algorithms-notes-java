# 27. Remove Element

- Сложность: Easy
- Темы: массив, два указателя
- Ссылка: https://leetcode.com/problems/remove-element/

## Условие

Нужно удалить из массива все вхождения `val` на месте и вернуть количество оставшихся элементов `k`. Правильный результат должен находиться в первых `k` позициях. Физическая длина Java-массива не меняется.

## Решение

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int write = 0;

        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != val) {
                nums[write] = nums[read];
                write++;
            }
        }

        return write;
    }
}
```

## Как работают указатели

- `read` проверяет очередной элемент.
- `write` равен числу сохранённых элементов и указывает следующую позицию записи.

Перед каждой итерацией диапазон `[0, write)` содержит все элементы, не равные `val`, из уже просмотренной части массива.

Одного увеличения `write` недостаточно. Без присваивания подходящие значения не переместятся в начало. Например, для `[3, 2, 2, 3]` можно вернуть `2`, но первые две позиции останутся `[3, 2]` вместо `[2, 2]`.

## Сложность

- Время: `O(n)`.
- Дополнительная память: `O(1)`.
