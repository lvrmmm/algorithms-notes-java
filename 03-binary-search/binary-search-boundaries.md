# Поиск границ бинарным поиском

Обычный бинарный поиск может вернуть любое вхождение повторяющегося значения. Чтобы найти первое или последнее вхождение, поиск продолжается после совпадения.

## Первое вхождение

При равенстве индекс сохраняется как кандидат, после чего поиск продолжается слева:

```java
int answer = -1;
int left = 0;
int right = nums.length - 1;

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (nums[mid] == target) {
        answer = mid;
        right = mid - 1;
    } else if (nums[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
```

## Последнее вхождение

При равенстве поиск продолжается справа:

```java
int answer = -1;
int left = 0;
int right = nums.length - 1;

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (nums[mid] == target) {
        answer = mid;
        left = mid + 1;
    } else if (nums[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
```

## Важные детали

Перед вторым независимым бинарным поиском границы нужно установить заново.

Ветки сравнения должны быть взаимоисключающими. При нескольких отдельных `if` после обработки равенства может выполниться ещё одна ветка и изменить вторую границу.

Два бинарных поиска всё равно занимают `O(log n)` времени:

```text
O(log n) + O(log n) = O(log n)
```
