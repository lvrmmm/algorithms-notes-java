# Бинарный поиск

Бинарный поиск применяется к отсортированным данным или к диапазону, в котором проверяемое условие меняется монотонно.

На каждой итерации рассматривается середина текущего интервала. Благодаря порядку данных можно исключить половину оставшихся кандидатов.

## Закрытый интервал `[left, right]`

В текущих реализациях обе границы входят в область поиска:

```java
int left = 0;
int right = nums.length - 1;

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (nums[mid] == target) {
        return mid;
    } else if (nums[mid] > target) {
        right = mid - 1;
    } else {
        left = mid + 1;
    }
}
```

Условие `left <= right` позволяет проверить интервал из одного элемента. После завершения поиска `left > right`, поэтому интервал пуст.

## Вычисление середины

```java
int mid = left + (right - left) / 2;
```

Такая запись избегает возможного переполнения выражения `left + right`.

## Что может возвращать бинарный поиск

Бинарный поиск используется не только для точного совпадения. Он может находить:

- любой элемент, равный цели;
- позицию вставки;
- первое или последнее вхождение;
- первый элемент, строго больший цели;
- первую позицию, где монотонное условие становится истинным;
- числовой ответ в заданном диапазоне.

## Сложность

- Время: `O(log n)`.
- Дополнительная память итеративной реализации: `O(1)`.
