## Как устроен разбор задачи

Каждая задача содержит:

1. ссылку на оригинальное условие;
2. краткое описание и пример;
3. идею решения;
4. реализацию на Java;
5. объяснение корректности;
6. оценку времени и памяти;
7. пограничные случаи и личные заметки;
8. альтернативные решения, если они разбирались.

Шаблоны находятся в папке [`templates`](templates/).
