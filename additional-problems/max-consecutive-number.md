# Максимальная серия одинаковых элементов

## Условие

Дан непустой массив целых чисел. Нужно вернуть длину самой длинной серии одинаковых элементов, расположенных подряд.

```text
[1, 1, 0, 0, 0, 1] -> 3
[3, 3, 7, 7, 7, 2] -> 3
[1, 0, 1, 0]       -> 1
```

## Решение

```java
public static int maxConsecutiveNumber(int[] nums) {
    if (nums.length == 0) {
        return 0;
    }

    int count = 1;
    int max = 1;

    for (int i = 1; i < nums.length; i++) {
        if (nums[i - 1] == nums[i]) {
            count++;
            max = Math.max(max, count);
        } else {
            count = 1;
        }
    }

    return max;
}
```

`count` хранит длину текущей серии. При смене значения текущий элемент начинает новую серию длины один.

В отличие от задачи `Max Consecutive Ones`, здесь значение элемента не имеет значения. Сравниваются текущий и предыдущий элементы.

## Сложность

- Время: `O(n)`.
- Дополнительная память: `O(1)`.
