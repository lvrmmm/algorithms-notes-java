# Пузырьковая сортировка

## Идея

Алгоритм последовательно сравнивает соседние элементы. Если левая пара больше правой, элементы меняются местами. После одного полного прохода наибольший элемент необработанной части оказывается справа.

## Реализация

```java
public static void bubbleSort(int[] array) {
    for (int i = 0; i < array.length - 1; i++) {
        boolean swapped = false;

        for (int j = 0; j < array.length - i - 1; j++) {
            if (array[j] > array[j + 1]) {
                int temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
                swapped = true;
            }
        }

        if (!swapped) {
            return;
        }
    }
}
```

## Инвариант

После `i` проходов последние `i` элементов находятся на окончательных позициях.

Если за полный проход не было обменов, вся необработанная часть уже отсортирована. Флаг `swapped` позволяет завершить работу раньше.

## Сложность

- Лучший случай: `O(n)` благодаря раннему выходу.
- Средний и худший случаи: `O(n²)`.
- Дополнительная память: `O(1)`.

## Важная деталь

Для сортировки по возрастанию условие обмена выглядит так:

```java
array[j] > array[j + 1]
```

Обратное сравнение формирует порядок по убыванию.
