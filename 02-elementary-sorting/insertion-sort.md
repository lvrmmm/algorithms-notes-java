# Сортировка вставками

## Идея

Массив делится на отсортированную и необработанную части. На каждой итерации следующий элемент сохраняется в `value`, большие элементы отсортированной части сдвигаются вправо, а `value` вставляется в освободившуюся позицию.

## Реализация

```java
public static void insertionSort(int[] array) {
    for (int out = 1; out < array.length; out++) {
        int value = array[out];
        int in = out;

        while (in > 0 && array[in - 1] > value) {
            array[in] = array[in - 1];
            in--;
        }

        array[in] = value;
    }
}
```

## Пошаговый пример

```text
[2, 4, 5, 3]  value = 3
[2, 4, 5, 5]  сдвигаем 5
[2, 4, 4, 5]  сдвигаем 4
[2, 3, 4, 5]  вставляем 3
```

## Инвариант

Перед итерацией с индексом `out` диапазон `[0, out)` уже отсортирован.

## Сложность

- Лучший случай: `O(n)` для отсортированного массива.
- Средний и худший случаи: `O(n²)`.
- Дополнительная память: `O(1)`.

## Строгое сравнение

При условии `array[in - 1] > value` равные элементы не сдвигаются, поэтому алгоритм остаётся устойчивым.

Если использовать `>=`, итоговый массив тоже будет отсортирован, но равные элементы могут поменять взаимный порядок. Для массива одинаковых значений число сдвигов вырастет с нуля до `n(n - 1) / 2`.
